# Painel de BI — Assistência Técnica de Celulares

Painel feito em Python e Streamlit para uma assistência técnica de celulares. Ele mostra
quantos aparelhos entram e saem, quanto tempo os reparos levam, quais defeitos são mais
comuns, quais consertos voltam na garantia e quais serviços dão mais dinheiro, para ajudar
o dono a decidir onde melhorar.

> **Aviso:** os dados usados neste projeto são **simulados**, criados com base em
> informações passadas pela empresa. Eles não são os dados reais da assistência.

## Como rodar

```bash
pip install -r requirements.txt
python gerar_dados.py
python limpar_dados.py
streamlit run app.py
```
